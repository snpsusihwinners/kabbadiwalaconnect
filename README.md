# KabaddiWala Connect (EcoSetu)

**Author:** Akash HG  
**Project:** EcoSetu — Digitizing and connecting local scrap collectors (Kabaddiwalas) with recyclers.

---

## 🌟 Overview

**KabaddiWala Connect (EcoSetu)** is a comprehensive web platform designed to streamline and empower the informal waste collection and recycling ecosystem. It bridges the gap between grassroots scrap collectors (Kabaddiwalas) and certified industrial recyclers, enabling fair market pricing, digitized waste lots, QR-verified handovers, and end-to-end supply chain traceability.

---

## 🚀 Key Features

### For Scrap Collectors (Kabaddiwalas)
- **Lot Creation & Management:** Log collected scrap with weight estimates, categories (paper, plastic, e-waste, metals), and geo-tagging.
- **Transparent Market Pricing:** Real-time visibility into scrap prices across different material categories.
- **Find Recyclers:** Locate authorized local recycling facilities and centers nearby.
- **Digital Handover:** Generate QR codes and secure transaction codes for instant verification and weighing at recycling centers.
- **Earnings & History:** Track income, completed handovers, and historical transactions.

### For Recyclers
- **Incoming Lots Management:** Review incoming scrap batches submitted by collectors in real time.
- **QR Code Verification:** Scan and verify lots on arrival, update measured weights, and approve payouts.
- **Supply Chain Traceability:** Maintain an immutable record of materials from collection to processing.
- **Operations Dashboard:** Track recycling volumes, material breakdowns, and processing metrics.

## 🛠️ Tech Stack

- **Frontend Framework:** React 19 with TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS
- **Routing:** React Router v7
- **Icons & Animation:** Lucide React, Framer Motion
- **Utilities:** `qrcode.react`, `clsx`, `tailwind-merge`

## 💻 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/snpsusihwinners/kabbadiwalaconnect.git
   cd kabbadiwalaconnect
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview production build:
   ```bash
   npm run preview
   ```
